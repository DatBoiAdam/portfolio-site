### Intro
This tutorial will describe how to set up a basic, functional Java Developer environment. As a good security practice, please make sure to never install software from the internet without verifying it's source. 

### Intalling your IDE 
1. For this example, we will be using Eclipse as our IDE (Integrated Development Enviroment). This is the program you will use to write and test your code. To begin, download it from [**here**](https://www.eclipse.org/downloads/packages/release/2026-09/r/eclipse-ide-java-developers). Make sure to select the appropriate version for your computer.
2. Download the Adoptium Temurin Java package [**here**](https://adoptium.net/). It should autodetect your system to provide you the correct file. This is an open source (free) version of the Java binary. The Java binary is what our code will interact with.
3. Now that you have both programs downloaded, lets run the eclipse installer.
